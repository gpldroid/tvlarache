## العربية

### 📋 نظرة عامة
**LARACHE TV** هي منصة بث مباشر متكاملة تقدم تجربة مشاهدة استثنائية لمحبي المحتوى العربي والعالمي. تتيح المنصة للمستخدمين مشاهدة آلاف القنوات التلفزيونية المباشرة من مختلف الدول مجاناً وبجودة عالية.

### ✨ المميزات الرئيسية

#### 📺 **البث المباشر**
- قنوات من **35+ دولة** مختلفة
- تصنيف القنوات حسب **الدولة والفئة**
- دعم جودة تصل إلى **4K UHD**
- واجهة مستخدم عربية بديهية

#### ⭐ **نظام المفضلة**
- حفظ القنوات المفضلة
- تخزين محلي على المتصفح
- وصول سريع للقنوات المحببة

#### 🔍 **بحث متقدم**
- بحث ذكي عن القنوات
- فلترة حسب الدولة والفئة
- نتائج فورية أثناء الكتابة

#### 🎨 **واجهة مستخدم متطورة**
- تصميم عصري مع أنميشنات
- **وضع داكن/فاتح** متكامل
- تصميم متجاوب يعمل على جميع الأجهزة
- تحسين أداء وسلاسة التصفح

#### 📱 **ميزات إضافية**
- **رفع قوائم M3U** المخصصة
- زر **"تحميل المزيد"** للقنوات
- معلومات تفصيلية عن كل قناة
- تشغيل مباشر بدون حاجة للتثبيت

## English

### 📋 Overview
**LARACHE TV** is a comprehensive live streaming platform offering an exceptional viewing experience for lovers of Arabic and international content. The platform allows users to watch thousands of live TV channels from different countries for free in high quality.

### ✨ Key Features

#### 📺 **Live Streaming**
- Channels from **35+ countries**
- Categorization by **country and category**
- Support up to **4K UHD quality**
- Intuitive Arabic user interface

#### ⭐ **Favorites System**
- Save favorite channels
- Local browser storage
- Quick access to preferred channels

#### 🔍 **Advanced Search**
- Smart channel search
- Filter by country and category
- Instant results while typing

#### 🎨 **Advanced UI**
- Modern design with animations
- **Dark/Light mode** integration
- Responsive design for all devices
- Optimized performance and smooth browsing

#### 📱 **Additional Features**
- **Upload custom M3U** playlists
- **"Load More"** button for channels
- Detailed information for each channel
- Direct playback without installation

### 🚀 Technologies Used

| Technology | Usage |
|------------|-------|
| **HTML5** | Main page structure |
| **CSS3** | Design and styling |
| **JavaScript** | Interaction and logic |
| **Plyr.js** | Video player |
| **HLS.js** | HLS streaming support |
| **Font Awesome** | Icons |
| **Tailwind CSS** | Some pre-built components |
